# Prism 产品定义

Prism 是一个**可验证的方案选型工作台**。用户提出要比较的方案、硬条件和偏好，Agent 研究并核对候选资料，用户在画布验证不同假设，最后形成一份有推荐、备选、引用和核对事项的**决策建议书**。

## 为谁解决什么问题

面向需要查资料、比较多个约束、反复修改要求的选型任务。可以提出设备选购、技术方案、工具与服务等问题，实际结果取决于取得的资料。画布承载方案与假设，问答解释取舍，建议书承担交付。

一个任务应回答：现在更建议关注什么，为什么保留其他备选，改变哪个条件会影响结论，以及决定前还缺什么信息。

商品选型还需要回答「从哪里买」。同一配置的商家报价单独组织，在画布比较来源、标价和购买条件；切换报价建立新分支，不把不同卖家的价格当成硬件参数冲突。见[同款多来源比价](MULTI-SOURCE-OFFERS.md)。

## 一条完整的使用流程

1. **说明选型问题。** 输入比较目标，可补充不能妥协的条件、偏好与交付重点。
2. **研究候选。** 现有规划、研究、审查、分析角色取得来源绑定的事实；未知保持未知，无法取得有效候选时继续保留问题。
3. **画布验证。** 条件调整直接重算，保留父分支和原始情况；观察进入、退出和排除原因，按关键缺口定向补查。
4. **形成建议书。** 同一份数据组织当前建议、实际取舍、备选方案、已有推演、引用底稿与核对清单；已有可用问答建议可以复用。
5. **记录个人选择。** 用户确认倾向与理由后，保存当时的条件和依据。模型解读不能替用户完成确认。
6. **导出与复核。** Markdown 建议书可直接阅读，JSON 保留完整空间；条件、资料或任务背景变化后，旧建议与旧选择分别检查是否仍适用。

初次进入仍以 What-if 画布为主工作区；用户主动打开建议书或资料后，当前会话中刷新可保留所处视图。

## 决策建议书包含什么

- 当前问题、条件、候选范围及资料状态。
- 当前建议与具体参数依据，明确区分规则初筛、模型参与的建议和导入的历史分析。
- 可保留的备选，以及在已知比较维度上需要接受的取舍。
- 已有分支推演与尚未应用的条件假设，支持回到画布继续验证。
- 程序回填的原文、采集时间、来源链接和决定前的核对事项。
- 人工记录的选择与理由；其他分支或旧资料下的选择明确提示复核。

生成选型解读是只读分析：使用当前分支已有资料，不接受模型修改条件或启动新研究的指令。资料不足时输出未完成状态。定向补查是另外的明确操作，保留原始分支。任务备忘是用户背景，不作为网页事实。

## 验收与下一步

验收应走完整任务：提出选型问题，取得可比较候选，解释一次取舍，在画布验证假设，形成引用对应的建议书，再由用户记录选择。软件回归数量与真实任务质量分别记录。

后续优先改善真实资料覆盖、用户材料接入、跨来源实体核对和建议书分享。当前已有 JSON 导入、来源重读和判断复核；PDF／表格任意建库、持续来源监控及托管协作分享尚未实现。

执行控制与研究进度保留在后台，前端呈现选型结果与操作反馈。
