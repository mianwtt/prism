Captured real records are not bundled as first-run demo data; portable examples and startup demos are explicitly fictional. The images demonstrate product interactions, not current listing availability or independent verification of publishers' claims.

The overview's visual grouping was informed by [AutoGen, Figure 1](https://arxiv.org/html/2308.08155v2), [AgentScope, Figure 1](https://arxiv.org/html/2402.14034v2) and [OpenHands, Figure 2](https://arxiv.org/html/2407.16741v2). Their component grouping and separation of overview/detail informed the presentation; Prism's modules and connections follow its own source code. The reference figures are not bundled with the project.
