**Prism—多 Agent 研究与交互式决策平台**

**技术栈：** Node.js、LangGraph、MCP、SearXNG、Redis、SQLite、Playwright。

**项目描述：** 面向选购、租房等多条件决策，Agent 检索核验真实资料，比较候选方案及同款商家报价；用户通过 What-if 画布调整条件、切换报价，查看候选变化和排除原因，生成带来源依据与待核对事项的决策建议书。

**项目实现：**

- **多 Agent 编排与恢复：** 基于 **LangGraph 子图**编排协调、研究、审查、分析四类角色，按需加载 Skills，以**上下文投影与工具白名单**隔离职责；审查驱动定向补查，结合 **SQLite Checkpoint** 支持阶段恢复。
- **多源检索与同款比价：** 经 **MCP** 接入 SearXNG、商家目录与 Edge 读页，按型号、配置及套餐核对同款，将**商品配置与商家报价分离建模**，保留原文和采集时间，过滤条件价、缺货与失效价；无预填链接的真实任务取得 **2家商家的同款报价**，35条证据规则回归全部通过。
- **What-if 推演与决策交付：** 采用**分支继承与显式覆盖**，共享内核执行约束过滤与加权评分；切换报价另建分支，建议书绑定当前条件与引用。9个合成候选、7个情景、1000次重算，内核 **P95 0.66ms**。
- **Redis 缓存与访问优化：** 以 **Read-through＋TTL** 缓存搜索结果，通过**进程内 Promise 复用**合并同键请求，缓存故障时降级直查；3组查询各重复3次，相比关闭缓存，外部加载由 **9次降至3次，减少66.7%**。
