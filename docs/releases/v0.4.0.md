# Prism 0.4 — public preview

**Research the choices. Explore the what-ifs. Keep the evidence.**

Prism connects an AI research agent to an interactive decision canvas. A changed budget, requirement or preference creates a visible path through the same evidence, so the conversation can continue beyond a one-off recommendation.

## What you can do

- Ask the LangGraph Agent to find and read public information, with comparison dimensions shaped by your question.
- Explore connected What-if branches while keeping the original situation. Edit a condition and see matching choices change; descendants inherit changes while explicit overrides remain their own.
- Click an option's photograph to inspect details, quotations and source links in a floating window.
- Continue the conversation, request further research on a selected path, and compare any two branches.
- Save the reasons for a decision, revisit the evidence, export/import a separate copy, or delete its local history.
- Try fictional laptop and housing examples without a model or commercial search key. Connect Ollama and optional tofu-search for live research.

## Start locally

Use Node 24 (recommended) or a current Node 22 release, at least 22.9:

```sh
npm ci
npm start
```

Open [localhost:4317](http://localhost:4317). The interface currently uses Chinese. See [setup](../SETUP.md) for model and search configuration.

## Validation and scope

Historical published CI verified its own revision. The current source regression, actual Edge interaction checks, clean-source verification and frozen real research batches are recorded in the [2026-11-18/19 quality report](../reports/PREVIEW-QUALITY-2026-11-18.md). Intermediate failures are retained; a successful single task does not replace a complete batch. Inspect the Checks workflow for the specific published commit; local verification does not establish remote CI success.

This is a local single-user preview. Model quality, search recall, public-page access and source freshness can still limit live research. Source quotations establish provenance, not independent truth. Current live rental checks primarily use Fang.com; they are not cross-platform verification or a general success-rate estimate. PDF/Word/Excel/image ingestion is not implemented. The base Docker image does not bundle the Python/tofu/browser stack for no-key research; its basic runtime smoke is not a full Agent container test. Docker Desktop could not start during current checks. Remote CI status must be read for the actual source revision.
