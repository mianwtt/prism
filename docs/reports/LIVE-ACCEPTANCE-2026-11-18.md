## 验收协议

[固定任务](../../tests/fixtures/research-acceptance-tasks.json)包含电脑五项、五个城市的整租任务各一项。每项至少取得三个不同商品配置或房源；全部明确数值条件有引用支持，并取得与对应来源绑定、实际能加载的原页图片。库存不参与筛选，不登录，不使用新闻首发价、起价或有条件优惠价。

批次记录运行代码、任务集和配置指纹；版本或配置变更会停止该批次，不能拼接成一组固定版本结果。评估进程关闭应用搜索缓存，不修改本地设置；模型仍使用当前本机配置。原始日志保存在忽略的 `work/live-acceptance/`，公开报告不包含密钥、私有配置或整份第三方正文。

## 本轮修复

```mermaid
flowchart LR
  Q[用户的自然语言需求] --> P[Agent 选择比较条件和目录类别]
  P --> C[读取公开商品目录中的实际链接]
  C --> D[读取同一商品的标价、规格表和原图]
  P --> S[tofu 发现公开来源]
  S --> D
  D --> V[实体、引文、类型和单位校验]
  V --> R[不足时按预算继续补查]
  R --> W[保留带来源的比较方案与 What-if]
```

- **商品发现**：新增公开目录工具，由 Agent 选择类别，而非代码预设电脑品牌和型号。大规划响应漏掉工具选择时，用一次简短模型调用补齐；平台白名单和调用数量由应用约束。
- **商品读取**：公开标价、参数表和照片按商家/商品编号绑定，初次读取和补查复用同一读取器；不以库存为取数前提，不使用目录封面代替具体商品照片。
- **字段映射**：只将实际观察到的参数映射到 Agent 选出的字段，进行 GB/TB、kg/千克等换算；缺失、冲突、可选容量及未证明为固态的硬盘信息不会补成事实。
- **来源复核**：新页面不再支持照片或报价时撤回相关观察；保留历史版本。
- **规划修复**：无约束且没有分类选项的名称/型号列视为身份元数据；不会因此新增图片条件或删除用户明确的品牌偏好。

这些是平台读取适配，不是为前端固定一套电脑字段。住房继续使用同一研究图、字段契约和比较内核，来源解析由房天下读取器处理。

## 定向修复与复测

完整批次结束后，单独修复以下问题，再运行 C02、C03、C05、R04，不与前一批次拼接为新的十项通过率：

1. 将来源链接、来源图片和原图验证等过程元数据移出比较字段，保留用户的证据要求；不改写用户价格、内存、重量等限制。
2. `房源类型` 若明确使用整租/合租选项，则绑定当前详情页实际出租方式。
3. 对过长的目录关键词补一次简短类别选择，减少用途描述进入站内查询。
4. 独立验收同时要求原始任务条件通过及应用实际可以比较，新增相关回归。

## 剩余发布门槛

- 低预算和32GB电脑的候选发现仍会选到明显昂贵或较重的商品，部分促销样式的普通标价不能稳定读取。
- 上海、深圳任务没有形成可比较房源；需要继续改善对已观察到的筛选目录和详情页样式的利用，不能仅重试同样的长查询。
- 最终版本仍需重新执行完整固定任务及另外的未见任务；当前十项已经用于调试，不能再称为留出集。
- 未完成独立逐字段人工标注、等预算对手比较或用户决策效率实验。当前结果不足以支持“成熟版”“任意场景都能研究”或“准确率提升X%”的发布表述。

## 结果的解释边界

达标表示保存的来源、条件覆盖和图源加载通过本协议。它不等于发布者信息真实、照片一定代表具体配置外观、房源实时有效或跨平台独立核实，也不等于逐字段人工标注正确率。对同一平台的参数和标价读取不能包装成两个独立信息源。线上网页和模型输出会变化；本报告不会把失败删掉或改成演示数据。

要量化“比普通模型加搜索更好”，仍需固定对手、同等工具与资源预算的配对比较，以及独立标注集；本轮结果只提供真实任务覆盖和工程回归证据。
