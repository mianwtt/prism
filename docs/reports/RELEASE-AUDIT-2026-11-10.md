## 4. 本轮已修复并增加回归的缺陷

1. **资料复核沿用旧配图。** 新页面已更新或读取失败时，原配图可能继续被当成当前页面图片。现在对同一房源重新绑定最新室内图；无法重新核对时撤下当前配图，历史版本保留。
2. **抓取图片范围过宽。** 租房详情解析原先扫描全页室内图标签，可能混入推荐区。现限定主相册，并在页面提供结构化房源信息时校验房源 URL 与主价格，拒绝身份或价格不一致的页面。
3. **把取证要求当成评分维度。** 模型可能生成“有原页图片／有室内图”等条件，导致图片证据要求变成额外的事实缺口。现会校验并要求模型修复，不能以猜测的布尔值填补。
4. **空结果没有再次尝试其他来源。** 新增一次有明确查询、读页和详情数量上限的补查；列表只提供实际观察到的详情链接供 Agent 选择。受控回归通过，但真实实测仍不足，未把这项修改写成研究质量已达标。
5. **租赁方式枚举没有利用详情原值。** 原页明确给出整租／合租时，可向 Agent 选择的相应枚举维度提供有引文的值；不添加新的需求门槛。
6. **可读性与辅助语义。** 提升浅色小字的对比度，纠正普通按钮不适用的 `aria-selected`，增加减少动态效果的支持。保留现有布局与配色体系。
