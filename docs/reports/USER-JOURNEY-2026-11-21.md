# 真实使用模拟、交互修复与流程澄清

整理日期：2026-11-21。这里记录上一轮 Microsoft Edge 模拟使用和本轮文档流程修订。原始实验目录保留 `2026-11-20` 日期，失败记录未覆盖。

## 实际复现的五个问题

| 操作 | 原来的问题 | 修复后的行为 |
| --- | --- | --- |
| 取消房源区域限制，再想恢复 | 零权重的区域字段变成不限后，侧栏控件消失 | 基线中明确使用的条件保留控件，能直接恢复 |
| 手动改条件后切换空间或刷新 | 新分支、条件和输入内容只在渲染器内存中，可能丢失 | 按不可变版本保存本机浏览器草稿，恢复时校验条件和分支作用域 |
| 不先保存，直接导出当前画布 | 文件来自旧的服务器快照，预算仍是旧值 | 导出当前条件与分支，原始情况和来源快照保留，服务器旧版本不改写 |
| 在北京海淀发起全新租房研究 | 模型把“北京海淀”整个作为城市名传入，目录工具无法找到城市 | 在真实城市索引中匹配城市前缀，再沿观察到的区域入口继续核对；不猜城市代码 |
| 取消整租后说“还是整租吧” | 模型口头确认恢复整租，实际条件仍是不限 | 优先识别现有枚举选项，执行受校验的操作，再生成实际结果说明 |

浏览器草稿仅保留条件、分支 ID、可见路径和未提交输入；不替换已保存的事实或原文。草稿属于当前站点和浏览器。删除决策空间时同步清除该家族在当前浏览器中的草稿，不删除其他空间或导出的独立备份文件。

## 实际服务上的连续操作

使用已有公开来源的租房和笔记本记录副本，运行本机实际配置的服务。没有替换研究、模型或 HTTP 响应，没有构造房源照片，没有改动用户原始决策目录。类型明确的条件操作由代码执行，不需要每条都调用模型。

最终连续重放 11 项通过：

1. 取消、恢复区域条件。
2. 手动调整预算，切换空间再返回。
3. 直接导出当前未保存的预算和分支。
4. 清除整租后通过口语恢复。
5. 同时修改租金与面积，再撤销。
6. 点图片打开浮窗，查看原文来源，再返回画布。
7. 手机尺寸下恢复区域，检查整页横向溢出。
8. 从笔记本基线建立本地分支，确认保存前后候选范围没有无故扩大。
9. 输入双侧预算区间，确认说明暂不支持且原条件不变。
10. 重新导入实际下载的 JSON，核对当前预算、原始条件和原图 URL。
11. 先取消删除，再删除导入副本，核对本地文件和浏览器草稿消失、原记录仍在。

补充的受控浏览器回归覆盖草稿刷新、未发送问题和判断文本保留，以及导入、删除和待处理对话的导航行为。首次脚本中的导出链接文字和部分选择器不准确，导致测试中断；脚本修正后重新执行，没有把这些脚本问题计为产品缺陷。

## 新城市研究复测

相同输入从首页重新发起研究，输入中没有具体房源链接：

> 在北京海淀租房，月租不超过5000元，面积至少25平方米，只看整租，需要原房源图片。不限制通勤，请找几个具体房源进行比较。

| 阶段 | 可比较房源 | 城市与区域 | 首页研究耗时 |
| --- | ---: | --- | ---: |
| 修复前 | 0 | 城市目录输入未解析成功 | 123.7 秒 |
| 修复后 | 6 | 7 条采集记录的详情均为北京海淀，6 条满足全部要求 | 52.8 秒 |

原页照片在实际 Edge 页面中加载。重复分支中同一照片出现多次，不将页面上的图片节点数当成独立房源数。独立验收同时核对租金、面积、整租方式、同一房源主信息中的城市/行政区与图片来源。

这是一次故障复现后的新城市回归，不是未见任务成功率，也不能说明所有城市和网站都已覆盖。

## 为什么旧流程图容易误导

旧图把用户操作、LangGraph、模型调用、搜索和存储放到一条线上。现在主图只保留应用层的三条路径：

| 本轮请求 | 执行路径 |
| --- | --- |
| 新问题、补充来源或新的比较依据 | 研究任务 → LangGraph → 读取并校验资料 → 更新决策空间 |
| 改变已有条件 | 条件校验 → 确定性评估器 → 当前分支重算 |
| 询问已有选择 | 当前路径和对话上下文 → 解释或澄清；必要时调用模型 |

模型和读页服务是按需调用的依赖；SQLite 保存研究检查点，JSON 保存业务版本，可选 Redis 缓存搜索。这些组件不构成“必须挨个经过”的用户流程。后续对话重新沿相应路径处理，不意味着每次聊天都会重新研究。

## 验证与边界

- 最近一次完整回归：293 项单元／HTTP、71 项 Edge 浏览器测试通过；分类短句匹配的小修订后，39 项条件／对话专项通过。
- 真实连续使用重放：11 项通过，无页面脚本异常。
- 新城市独立验收：由 0 个恢复到 6 个符合完整要求的房源。
- 双侧数值区间仍是已确认的功能限制。当前能说明限制并保持条件不变，尚未实现上下限共同筛选。
- 页面不可读、没有足够依据仍可能产生零结果；不能用这一轮成功推导全平台可靠性。本轮没有新增 Docker、远程 CI 或跨浏览器验收。

本地完整证据在 `work/user-journey-2026-11-20/review.json`、`final-lifecycle/journey.json` 及 `human-beijing-haidian*` 实验目录中；这些运行资料不随源码发布。代码入口见 [workspace-draft.mjs](../../src/workspace-draft.mjs)、[conversation-intent.mjs](../../src/conversation-intent.mjs) 和 [public-rental-read.mjs](../../src/public-rental-read.mjs)。
