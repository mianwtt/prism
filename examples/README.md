# Portable examples

These JSON files contain **fictional software-demo data**, not real products, listings, merchant offers or measured travel times.

- [Laptop](laptop.json): budget, RAM and portability, with three independent branches.
- [Housing](housing.json): rent, area and commute, with three independent branches.
- [Rental logic fixture](rental-showcase.json): four explicitly fictional records and five connected branches for testing interactions. It contains no generated or stock listing photographs. Real rental decisions use captured platform detail pages and their corresponding source images.

Download a JSON file, start Prism and choose **导入决策文件** in the sidebar. Import creates an independent decision space. No model, search key, login or external fetch is required.

These examples demonstrate the same renderer using different typed dimensions. They are not evidence that live extraction works on a particular platform.
